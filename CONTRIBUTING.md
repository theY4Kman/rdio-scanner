# Guide lines for contributing to [Rdio Scanner](https://github.com/theY4Kman/rdio-scanner)

Open any pull request you want.

## Support requests or general question

Support requests or general questions are welcome on the [Rdio Scanner Discussions](https://github.com/chuot/rdio-scanner/discussions). If you create an issue here, instead, it will be responded to kindly.

## Random Pull Requests

To keep the project fresh and community vibrant, random pull requests are welcomed! If you feel inspired enough to take time out of your day to add value to a project you enjoy, I would be ecstatic to take a look at it, and do the needful to get it merged!

## Bugs and feature requests

We use [GitHub Issues](https://github.com/chuot/rdio-scanner/issues) to track bugs and feature requests.

Open an [issue](https://github.com/chuot/rdio-scanner/issues) that best describes the bug or feature request.

For **bugs**, describe the environment in which you encounter it and explain step by step how to reproduce them.

For **feature requests**, describe the reason and use case.
